# Duke Coverup Timeline (Secure Investigative Briefing)

This repository contains a **password-protected investigative briefing** built with **Next.js**, designed to present a confidential, evidence-based timeline relating to the Jane Duke coverup case.

The site is deployed on **Vercel**, protected by **Edge Middleware Basic Auth**, and is intended for controlled access only (e.g., journalists, investigators, legal experts).

---

## 🚧 Important Notes

- This repository is **PRIVATE**.
- The deployed site is **password-protected** via Vercel Edge Middleware.
- The site content is generated from a custom HTML timeline embedded into the Next.js app.
- This project uses the **App Router** (`app/` directory).
